# Bundled Fonts (`assets/fonts/`)

Prism bundles permissively licensed (SIL Open Font License 1.1) metric-compatible fonts so that document layout, SVG outline generation, rasterization, and PDF export are **hermetic and byte-identical** across machines without querying host system fonts by default.
