# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

Please report any security vulnerabilities directly to abahjat@gmail.com.
We aim to acknowledge reports within 48 hours and provide updates on our investigation and resolution timeline.
